# Safety Road Watch

แอป Android แบบกล้องหน้ารถ สำหรับเก็บหลักฐานรถที่ทำผิดกฎจราจรในไทย แล้วส่งให้ตำรวจ (1197) หรือกรมการขนส่งทางบก (1584)

## ใช้งาน
1. ยึดมือถือหน้ารถ เปิดแอป แอปอัดวิดีโอวนเก็บไว้ประมาณ 30 วินาทีล่าสุด **ภาพอย่างเดียว ไม่อัดเสียง**
2. เจอรถทำผิด กดปุ่ม **🚨 จับ!** หรือปุ่มรีโมท Bluetooth (ปุ่มเสียง หรือปุ่ม play)
   - แอปเก็บคลิป 30 วินาทีก่อนกด และ 30 วินาทีหลังกด
   - ไมค์เปิดเฉพาะตอนนี้: พูดเช่น "ทะเบียน 8กค3692 นครราชสีมา ล้อล้น ควันดำ" แล้วกดอีกครั้ง (หรือรอ 12 วินาที)
   - เก็บไฟล์เสียงไว้ฟังย้อนหลัง แปลงเป็นข้อความ แล้วแยกทะเบียน จังหวัด และความผิดให้
3. หลังจอดรถ เปิด **คลัง** ฟังเสียง ดูคลิป เลือกท่อนที่ต้องการแล้วกดรวมเป็นคลิปเดียว แล้วกดแชร์ไป LINE หรือ Facebook ของหน่วยงาน

ห้ามใช้มือถือขณะขับ ใช้ปุ่มใหญ่หรือรีโมทเท่านั้น และอย่าโพสต์คลิปลงที่สาธารณะ

## ข้อจำกัด
- แปลงเสียงเป็นข้อความได้บน Android 13 ขึ้นไปเท่านั้น เครื่องที่เก่ากว่ายังเก็บไฟล์เสียงไว้ฟังได้
- ใช้ตัวรู้จำเสียงในเครื่องถ้ามี ถ้าไม่มีจะใช้บริการเสียงของเครื่อง (อาจต้องใช้เน็ต)
- ข้อมูลทั้งหมดอยู่ในเครื่อง ถ้าลบแอป ข้อมูลหายหมด

## ดาวน์โหลด APK
ทุก push จะสร้าง APK ใหม่ไว้ที่ release **latest** ของ repo นี้ (ใบรับรอง debug ตัวเดิมทุกครั้ง จึงติดตั้งทับได้โดยข้อมูลไม่หาย)

## Build
```
gradle assembleDebug   # Gradle 8.14, JDK 17, Android SDK 35
```
