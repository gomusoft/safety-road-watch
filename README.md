# Safety Road Watch

Lane: `direct` · Cost: none (no server; GitHub Actions is free for public repos)

**ถนนที่ปลอดภัย เริ่มจากคนธรรมดาที่ไม่นิ่งเฉย**

ทุกวันบนถนนเมืองไทยเราเห็นรถฝ่าไฟแดง ปาดเส้นทึบ ปล่อยควันดำ หรือดัดแปลงล้อจนล้นตัวถัง
แล้วส่วนใหญ่ก็ทำได้แค่บ่นแล้วขับต่อไป เพราะการเก็บหลักฐานยุ่งยากและอันตรายถ้าต้องหยิบมือถือ

Safety Road Watch ทำให้คนขับธรรมดาช่วยทำให้ถนนปลอดภัยขึ้นได้ โดยไม่ต้องละสายตาจากถนน:
กดปุ่มเดียว พูดสั้นๆ แล้วขับต่อ หลักฐานที่ชัดเจนจะรออยู่ในเครื่อง พร้อมส่งให้เจ้าหน้าที่
ตำรวจ (1197) หรือกรมการขนส่งทางบก (1584) เมื่อคุณจอดรถแล้ว

ความตั้งใจของเรา:
- **ปลอดภัยก่อนเสมอ** ใช้งานได้โดยไม่ต้องจับมือถือ
- **เคารพความเป็นส่วนตัว** ไม่อัดเสียงในรถ ไมค์เปิดเฉพาะตอนที่คุณกดสั่ง และข้อมูลทั้งหมดอยู่ในเครื่องของคุณเท่านั้น
- **ส่งให้เจ้าหน้าที่ ไม่ใช่ประจาน** หลักฐานมีไว้ให้กฎหมายทำหน้าที่ ไม่ใช่โพสต์ทำให้ใครอับอาย
- **เปิดเผยและฟรี** โค้ดเป็น open source ใครอยากช่วยพัฒนาเพื่อถนนที่ดีขึ้นก็มาร่วมได้

กฎจราจรที่ถูกบังคับใช้จริงช่วยรักษาชีวิตคนได้ และทุกคนบนถนนช่วยกันได้

## ใช้งาน
1. ยึดมือถือหน้ารถ เปิดแอป แอปอัดวิดีโอวนเก็บไว้ประมาณ 30 วินาทีล่าสุด **ภาพอย่างเดียว ไม่อัดเสียง**
2. เจอรถทำผิด กดปุ่ม **🛡️ บันทึก** (สีเขียวโปร่ง) หรือปุ่มรีโมท Bluetooth (ปุ่มเสียง หรือปุ่ม play)
   - แอปเก็บคลิป 30 วินาทีก่อนกด และ 30 วินาทีหลังกด
   - ไมค์เปิดเฉพาะตอนนี้: พูดเช่น "ทะเบียน 8กค3692 นครราชสีมา ล้อล้น ควันดำ" แล้วกดอีกครั้งเพื่อจบ หรือเงียบไป 8 วินาทีแอปจะจบเอง (ถ้าพูดต่อก่อนครบ 8 วินาทีก็อัดต่อ สูงสุด 45 วินาที) ระหว่างอัดเสียงปุ่มเป็นสีเหลืองกะพริบ และกดบันทึกเหตุการณ์ถัดไปได้ทันทีหลังจบ
   - เก็บไฟล์เสียงไว้ฟังย้อนหลัง แปลงเป็นข้อความ แล้วแยกทะเบียน จังหวัด และความผิดให้
3. หลังจอดรถ เปิด **คลัง** ดูพิกัด GPS ฟังเสียง ดูคลิป เลือกท่อนที่ต้องการแล้วกดรวมเป็นคลิปเดียว แล้วกดแชร์ไป LINE หรือ Facebook ของหน่วยงาน
   - ไฟล์ที่รวมแล้วอยู่ในแอป กด **บันทึกลงแกลเลอรี** ถ้าอยากเก็บไว้ดูนอกแอป (Android 10 ขึ้นไป)
   - ที่อยู่ (ถนน ตำบล อำเภอ จังหวัด) ดึงจาก GPS ได้ถ้าเปิดโหมดดึงที่อยู่ (ใช้เน็ต ต้องกดยอมรับก่อน) หลักกิโลดึงจากเสียงหรือพิมพ์เอง ทุกช่องแก้ได้ และบอกว่าได้มาจาก GPS เสียง หรือแก้เอง

ห้ามใช้มือถือขณะขับ ใช้ปุ่มใหญ่หรือรีโมทเท่านั้น และอย่าโพสต์คลิปลงที่สาธารณะ

## ข้อจำกัด
- แปลงเสียงเป็นข้อความได้บน Android 13 ขึ้นไปเท่านั้น เครื่องที่เก่ากว่ายังเก็บไฟล์เสียงไว้ฟังได้
- ใช้ตัวรู้จำเสียงในเครื่องถ้ามี ถ้าไม่มีจะใช้บริการเสียงของเครื่อง (อาจต้องใช้เน็ต)
- ข้อมูลทั้งหมดอยู่ในเครื่อง ถ้าลบแอป ข้อมูลหายหมด ยกเว้นโหมดดึงที่อยู่ (ปิดไว้เป็นค่าเริ่มต้น) ที่ส่งพิกัดให้บริการแผนที่ของเครื่องเมื่อคุณกดยอมรับ
- ไม่มีอินเทอร์เน็ตก็ใช้ได้ทุกอย่าง (อัด เก็บ ฟังเสียง รวมคลิป แชร์ แก้ที่อยู่เอง) ยกเว้นการดึงที่อยู่จาก GPS

## ดาวน์โหลด APK
เปิดลิงก์บนมือถือ ดาวน์โหลด แล้วติดตั้ง (ต้องอนุญาตติดตั้งจากแหล่งอื่นครั้งแรก)

**ควรใช้อันไหน:** ตอนนี้ใช้ **รุ่นทดสอบจาก `dev`** เพราะมีฟีเจอร์ใหม่ล่าสุด และรุ่นเสถียรยังไม่ออก เมื่อทดสอบแล้วผ่านและออกรุ่นแล้ว คนทั่วไปใช้ **รุ่นเสถียร** (Releases) ส่วน `dev` ไว้ทดสอบ อาจมีบั๊ก ลิงก์ `latest` จาก `main` จะเหมือนรุ่นเสถียรล่าสุด

- **รุ่นเสถียร:** [Releases](https://github.com/gomusoft/safety-road-watch/releases) (เช่น v0.1.0) พร้อมบันทึกการเปลี่ยนแปลง
- **รุ่นทดสอบจาก `dev`:** [dev-latest](https://github.com/gomusoft/safety-road-watch/releases/download/dev-latest/safety-road-watch.apk) สร้างใหม่ทุกครั้งที่มีการ merge เข้า `dev`
- **รุ่นล่าสุดจาก `main`:** [latest](https://github.com/gomusoft/safety-road-watch/releases/download/latest/safety-road-watch.apk)

ทุกรุ่นเซ็นด้วยใบรับรองตัวเดียวกัน จึงติดตั้งทับได้โดยข้อมูลไม่หาย
