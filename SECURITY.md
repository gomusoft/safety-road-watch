# Security and privacy

This app handles sensitive material: video of other people's vehicles, the user's voice and location.
Our promise: the mic is on only after the user presses capture, nothing is uploaded by the app, and data
leaves the phone only when the user presses Share.

## Reporting a problem
If you find a way the app records, stores or leaks more than it should, please report it privately through
GitHub's **Security → Report a vulnerability** on this repository instead of opening a public issue.
Do not attach real recordings of identifiable people or plates.

## Supported versions
Only the newest release receives fixes.
